How it works

A rejected or late item file costs you the ship window. Our process is built so the first file we submit is the right one.

We built the rule-set first for AAFES STEP/PIM. The same process — map, check, review, submit — applies to other retail and exchange systems; ask us about yours.

See the full process & FAQ →

  1. Send your data as it is

    A system export, line sheet, spreadsheet or feed. No reformatting on your side.

  2. Every field is checked against the buyer's rules

    Columns are mapped to the current PIM template and every value is tested: barcodes, required fields, dropdown lists, pricing and images.

  3. A person reviews every exception

    Anything the software can't prove is correct goes to a reviewer. Questions only you can answer come back in one list, not a stream of emails.

  4. You receive a ready file and a validation report

    We load the items into PIM, or hand you the finished template. See a sample report.

What we check on every file

Barcodes

Check digits, lost leading zeros, and spreadsheet damage such as “.0” endings and scientific notation. Try it on your own list.

Required fields

Every mandatory attribute for the item's category is present and in the right format.

Dropdown values

Colors, sizes, materials and units matched to the exact values the buyer's system accepts.

Pricing rules

MSRP is at or above unit retail, and prices are clean numbers.

Category attributes

Only attributes that belong to the item's category are sent, so none are rejected.

Product images

2000 × 2000 pixel JPEGs, named and matched to the right item before the upload window opens.
